# P2 적용 안내 — 월마감 + Google Chat + 구글 캘린더 구독

## 1. DB (먼저)
SQL Editor 에서 `03_p2_closing_chat.sql` 전체 실행 (01·02 적용된 상태에서, 이 파일만). 다시 실행해도 안전.
- 새 표: `closing_templates`, `closing_template_items`, `closing_runs`, `member_calendar_tokens`
- 추가 칸: `workspace_settings.holidays / chat_enabled / chat_enabled_at / chat_mention_by_email / chat_last_brief_date`, `notifications.chat_sent_at`, `tasks.closing_item_id` (+ `tasks.closing_run_id` 외래키)
- 새 함수(서버 전용): `nexus_create_closing_run`, `nexus_claim_chat_notifications`, `nexus_claim_daily_brief`
- `harim_nexus.notifications` 를 Realtime 발행 목록에 추가 (헤더 알림 실시간)

## 2. Google Chat 웹훅 주소 만들기 (팀장)
1. Google Chat 에서 팀 스페이스(예: 원가팀) 열기
2. 스페이스 이름 클릭 → **앱 및 통합** → **웹훅 추가(Add webhooks)**
3. 이름 `Nexus`, 아바타 URL 은 비워도 됨 → 저장 → 주소 복사 (`https://chat.googleapis.com/v1/spaces/...` 로 시작)
4. 이 주소는 비밀번호처럼 다룬다 (주소를 아는 사람은 스페이스에 글을 쓸 수 있음). 채팅에 붙이지 말 것
- Workspace 관리자가 웹훅을 막아 두었으면 메뉴가 안 보인다 → 사내 관리자에게 허용 요청

## 3. 환경변수 (`.env.local` + Vercel)
```
GOOGLE_CHAT_WEBHOOK_URL=<위에서 복사한 주소>
NEXT_PUBLIC_APP_URL=<배포 주소, 예: https://harim-nexus.vercel.app>   # 알림·캘린더 링크용
CRON_SECRET=<임의의 긴 문자열>                                        # Vercel 크론만 아침 작업을 실행하도록
```
- 크론: `vercel.json` → `/api/cron/daily` 매일 23:40 UTC(= 08:40 KST). 무료 프로젝트 일시정지 방지 조회 + (영업일이면) 월마감 자동 시작 + 밀린 Chat 알림 + 아침 브리핑
- `CRON_SECRET` 이 없으면 크론은 일시정지 방지 조회만 한다

## 4. 앱에서 켜기 (관리자, `/closing` → 관리자 설정)
1. **공휴일**: 기본값(2026-10 ~ 2027)은 참고용. 음력·대체·임시 공휴일과 회사 휴무일을 확인해 고친다
2. **템플릿 관리**: 템플릿 이름, 항목(이름·D+영업일·기본 담당자·참고 링크·설명). "매월 첫 영업일 아침 자동 시작" 선택 가능
3. **새 월마감 시작**: 템플릿·마감 대상월(기본: 지난달)·시작일(기본: 다음 달 첫 영업일) → 미리보기 확인 → 시작. 담당자에게 배정 알림
4. **Google Chat 알림**: 사용 켜기 → 연결 테스트 → (선택) 이메일 멘션

## 동작 규칙
- 월마감 업무는 일반 업무(`tasks`, `source='closing'`)라서 보드·홈·주간보고·캘린더에 그대로 나온다. 완료하면 AI 팀장 검토(`closing_item`) 대기열에 오른다
- 마감일 = 시작일(D+0)부터 영업일(주말·공휴일 제외) 기준. 시작일이 휴일이면 다음 영업일이 D+0
- 같은 템플릿·같은 대상월은 한 번만 시작 가능. 실행 기록이 있는 템플릿은 삭제 대신 "사용 중" 해제
- 지난달 비교: 같은 항목이 지난달 시작일로부터 몇 영업일째 완료됐는지 표시
- Chat 즉시 전송 대상: 업무 배정·댓글 멘션·확인된 고위험 AI 요약. 저장 직후 브라우저가 `/api/notify/flush` 를 부르고, 서버가 DB 에서 안 보낸 알림만 골라 1회 전송(동시 호출돼도 중복 없음). 켜기 전에 생긴 알림과 하루 넘은 알림은 보내지 않음. 전송 실패분은 다음 호출·아침 크론이 다시 시도
- 아침 브리핑: 평일·비공휴일, 하루 1회(DB 로 중복 방지). 오늘 마감·지연(각 8건까지 + 외 N건), 진행 중 월마감 진행률, AI 확인 대기 수. 금요일에는 주간보고 미제출자
- 이메일 멘션: 팀원 관리에 회사(구글) 이메일이 있고 설정을 켠 경우 `<users/이메일>` 형식. 실제 스페이스에서 멘션이 되는지 확인 필요 — 안 되면 끄면 이름으로 표시
- 캘린더 구독: 설정(톱니) → 구글 캘린더 구독 → 주소 만들기 → 구글 캘린더 "URL로 추가". 내 미완료 업무 마감일 + 근태만. 주소 재발급 시 예전 주소 즉시 무효. 토큰은 서버 전용 표(팀원끼리도 조회 불가)
